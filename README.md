# LUMOS Landing v2 — Wand Animation

## Chạy project

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Hiệu ứng v2

- Background tách riêng desktop/mobile
- Wand + glow là layer riêng
- Light burst là layer riêng
- Particles chuyển động bằng Framer Motion
- LUMOS reveal animation
- Button hover + scroll transition
- Hỗ trợ `prefers-reduced-motion`

## Assets

Tất cả asset nằm trong `public/assets/`.

Lưu ý: các layer PNG là bản tách tự động từ key visual gốc, dùng cho prototype v2.
